# Contributing to .NET Learning Journey

Thanks for helping grow this learning repo! Contributions of new notes and runnable C# examples are welcome from everyone, including first-time contributors.

## How to contribute

1. **Fork** this repository.
2. **Create a branch** named after your change, for example:
   - `docs/<topic>` for a learning note — e.g. `docs/model-binding`
   - `feat/<topic>` for a code example — e.g. `feat/binary-search`
3. **Make your change** (see the guidelines below).
4. **Commit** using a [Conventional Commit](https://www.conventionalcommits.org/) message, for example:
   - `docs(aspnet): add notes on model binding`
   - `feat(examples): add binary search C# example`
5. **Open a pull request** against the `main` branch and describe what you added and why it is useful.

## What makes a good note

- **Original content** — write it in your own words; do not copy text from books, docs or other sites.
- **One focused topic** — one concept per note, kept short and clear.
- **Correct and current** — the code and explanations should be accurate for the .NET stack used here.
- Put notes in the matching folder: `notes/csharp/`, `notes/aspnet/`, `notes/efcore/`, `notes/sql/` or `notes/dsa/`.

## What makes a good code example

- **Small and runnable** — a single `.cs` file in `examples/` with a `Main` demo that prints its result.
- **Correct code** — it must compile and run; keep it simple enough for a learner to follow.
- **Brief comments** — a short comment at the top explaining the idea, plus comments on the tricky parts.

## Not sure where to start?

Look at the issues labelled `good first issue` — they list notes and examples we would like to add.

Thank you for contributing! 🎉
